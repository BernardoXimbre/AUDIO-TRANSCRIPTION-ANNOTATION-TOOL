## ⚡ Exactly (Step-by-Step)

Create `apps/backend/prisma/schema.prisma`:

```prisma
// apps/backend/prisma/schema.prisma

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model AudioFile {
  id           String   @id @default(cuid())
  filename     String
  filepath     String   @unique
  duration     Float    // seconds
  sampleRate   Int      // Hz (e.g., 16000)
  channels     Int      // 1, 2
  bitDepth     Int      // 16, 24, 32
  bextMetadata Json?    // Optional BEXT metadata from file header
  
  transcripts  Transcript[]
  recording    Recording?
  
  createdAt    DateTime @default(now()) @db.Timestamptz(3)
  updatedAt    DateTime @updatedAt @db.Timestamptz(3)

  @@index([filename])
  @@index([createdAt])
}

model Transcript {
  id               String   @id @default(cuid())
  audioFileId      String
  audioFile        AudioFile @relation(fields: [audioFileId], onDelete: Cascade)
  
  originalText     String   // ✅ IMMUTABLE - AI's first-pass transcript
  correctedText    String   // Editable version by annotator
  
  status           String   @default("pending") // pending, in_progress, completed
  isAutoRejected   Boolean  @default(false)     // true if audio < 15s
  annotator        String?  // annotator name/ID (optional for MVP)
  
  annotations      Annotation[]
  
  createdAt        DateTime @default(now()) @db.Timestamptz(3)
  updatedAt        DateTime @updatedAt @db.Timestamptz(3)

  @@index([audioFileId])
  @@index([status])
  @@index([isAutoRejected])
}

model Annotation {
  id              String   @id @default(cuid())
  transcriptId    String
  transcript      Transcript @relation(fields: [transcriptId], onDelete: Cascade)
  
  type            String   // CRUD, NUMBER, FORMATTING_COMMAND, SPELLED_OUT, NAMED_ENTITY, MEDICAL_TERM, MEASUREMENT
  startOffset     Int      // Character position in correctedText
  endOffset       Int      // Character position in correctedText
  attributes      Json     // Type-specific attributes (flexible schema)
  
  createdAt       DateTime @default(now()) @db.Timestamptz(3)
  updatedAt       DateTime @updatedAt @db.Timestamptz(3)

  @@index([transcriptId])
  @@index([type])
}

model Recording {
  id                  String   @id @default(cuid())
  audioFileId         String   @unique
  audioFile           AudioFile @relation(fields: [audioFileId], onDelete: Cascade)
  
  // Derived values (calculated server-side, user-overridable)
  speechRate          Int?     // words per minute
  distanceEstimate    String?  // close, medium, far
  
  // Override flags (if user corrected the derived values)
  speechRateOverride  Int?
  distanceOverride    String?
  
  createdAt           DateTime @default(now()) @db.Timestamptz(3)
  updatedAt           DateTime @updatedAt @db.Timestamptz(3)
}
```

**Checklist**:
- [ ] `originalText` is never updated after creation (immutable)
- [ ] `isAutoRejected = true` for audio < 15s
- [ ] Annotation `attributes` is JSON (no strict schema at DB level, validation in service layer)
- [ ] Timestamps in UTC (`.db.Timestamptz(3)`)
- [ ] All relations use `Cascade` delete (cleanup safe)

## ✅ Review Checklist

### Schema Validity
- [ ] File created at `apps/backend/prisma/schema.prisma`
- [ ] Prisma validates schema: `yarn prisma validate` passes
- [ ] No syntax errors in schema

### Entity Completeness
- [ ] AudioFile: id, filename, filepath, duration, sampleRate, channels, bitDepth, bextMetadata
- [ ] Transcript: id, audioFileId, originalText, correctedText, status, isAutoRejected, annotations relation
- [ ] Annotation: id, transcriptId, type, startOffset, endOffset, attributes
- [ ] Recording: id, audioFileId, speechRate, distanceEstimate, overrides

### Relations
- [ ] AudioFile → Transcript (1-to-many)
- [ ] Transcript → Annotation (1-to-many)
- [ ] AudioFile → Recording (1-to-1)
- [ ] All use `onDelete: Cascade`

### Immutability & Rules
- [ ] originalText has no `@updatedAt` or update logic
- [ ] isAutoRejected field present (for auto-rejection rule)
- [ ] attributes is JSON type (flexible for 6 annotation types)

### Indexes for Query Performance
- [ ] Index on Transcript.status (for queue filtering)
- [ ] Index on Transcript.isAutoRejected (for queue filtering)
- [ ] Index on AudioFile.filename (for pairing lookup)
