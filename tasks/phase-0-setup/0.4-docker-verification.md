## 📋 Deliverable

**Verify**: Entire environment works end-to-end

---

## ⚡ Exactly

Run these steps in order:

```bash
# Terminal 1: Start Database
docker compose up -d

# Wait 5 seconds for PostgreSQL to start
sleep 5

# Terminal 2: Create schema
cd apps/backend
yarn prisma migrate dev --name init

# Terminal 3: Start Backend
yarn dev:backend

# Terminal 4: Start Frontend
cd apps/frontend
yarn dev:frontend

# Terminal 5: Test endpoints
curl http://localhost:5000/health
# Expected: { "status": "ok", "timestamp": "..." }
```

**Checklist**:
- [ ] `docker compose up -d` → PostgreSQL running
- [ ] `yarn prisma migrate dev` → Schema created
- [ ] `yarn dev:backend` → "✅ Backend running on http://localhost:5000"
- [ ] `yarn dev:frontend` → "✅ Vite dev server ready"
- [ ] Browser: `http://localhost:3000` → Page loads
- [ ] Browser: `http://localhost:5000/health` → JSON response
- [ ] Zero errors in both consoles

## ✋ Troubleshooting

| Issue | Solution |
|-------|----------|
| Docker won't start | Ensure Docker Desktop running |
| PostgreSQL connection fails | Check DB_URL env, port 5432 available |
| Prisma migrate fails | Delete `.env`, create new with DB_PASSWORD |
| Port 5000/3000 in use | Kill other processes: `lsof -i :5000` |
