## ⚡ Exactly

Create demo audio directory structure:

```
data/demo/audio/
├── sample_short.wav      (10 seconds) - Will be auto-rejected < 15s
├── sample_clean.wav      (20 seconds) - Clean speech
└── sample_noisy.wav      (45 seconds) - Speech with background noise
```

**Options for creating files:**

1. **Use existing open-source audio** (Mozilla Common Voice):
   - Download from https://commonvoice.mozilla.org/ (German language)
   - Use ffmpeg to trim/adjust duration:
   ```bash
   ffmpeg -i input.mp3 -t 10 -acodec pcm_s16le -ar 16000 -ac 1 sample_short.wav
   ffmpeg -i input.mp3 -t 20 -acodec pcm_s16le -ar 16000 -ac 1 sample_clean.wav
   ffmpeg -i input.mp3 -t 45 -acodec pcm_s16le -ar 16000 -ac 1 sample_noisy.wav
   ```

2. **Generate silence for testing**:
   ```bash
   ffmpeg -f lavfi -i anullsrc=r=16000:cl=mono -t 10 -q:a 9 -acodec libmp3lame sample_short.wav
   ffmpeg -f lavfi -i anullsrc=r=16000:cl=mono -t 20 -q:a 9 -acodec libmp3lame sample_clean.wav
   ffmpeg -f lavfi -i anullsrc=r=16000:cl=mono -t 45 -q:a 9 -acodec libmp3lame sample_noisy.wav
   ```

3. **Record your own**:
   - Use Audacity or terminal `sox` to record short German phrases
   - Export as 16-bit mono WAV at 16kHz

**File specifications:**
- Format: WAV (16-bit, 16kHz, mono)
- sample_short.wav: 10 seconds (auto-rejected, not in queue)
- sample_clean.wav: 20 seconds (clean audio, in queue)
- sample_noisy.wav: 45 seconds (with noise, in queue)
