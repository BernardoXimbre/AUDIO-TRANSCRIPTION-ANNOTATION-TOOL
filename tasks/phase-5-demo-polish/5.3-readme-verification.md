## ⚡ Exactly

Follow README literally on a clean machine/folder. All steps must complete:

1. [ ] `git clone https://github.com/BernardoXimbre/AUDIO-TRANSCRIPTION-ANNOTATION-TOOL.git`
2. [ ] `cd AUDIO-TRANSCRIPTION-ANNOTATION-TOOL`
3. [ ] Create `.env` with: `POSTGRES_PASSWORD=your_password`
4. [ ] `docker compose up -d` → PostgreSQL starts
5. [ ] `yarn install` → Dependencies installed
6. [ ] `yarn prisma migrate dev` → Schema created
7. [ ] `yarn seed` → Demo data loaded (2 items, 1 rejected)
8. [ ] Terminal 1: `yarn dev:backend` → Server running on 5000
9. [ ] Terminal 2: `yarn dev:frontend` → Vite dev server ready
10. [ ] Browser: `http://localhost:3000` → App loads
11. [ ] Navigate to `/queue` → 2 items visible (not 3, because 1 auto-rejected)
12. [ ] Click item → Annotator loads
13. [ ] Player works: Play/pause buttons functional
14. [ ] Editor shows: Original (read-only), Corrected (editable)
15. [ ] Can create annotation (select text, choose type, fill form)
16. [ ] Span renders with color
17. [ ] Can edit annotation (click span, modify form)
18. [ ] Can delete annotation
19. [ ] `/api/export` downloads JSONL file
20. [ ] JSONL is valid JSON (one object per line)
