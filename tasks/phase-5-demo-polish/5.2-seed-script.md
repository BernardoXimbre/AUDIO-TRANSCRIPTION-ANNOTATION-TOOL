## ⚡ Exactly

Create `data/demo/transcripts.json`:

```json
[
  {
    "path": "sample_short.wav",
    "label": "Das ist ein kurzer Test."
  },
  {
    "path": "sample_clean.wav",
    "label": "Kontrollierte Rückenlagerung des Patienten mit steriler Abdeckung und Kopftuch."
  },
  {
    "path": "sample_noisy.wav",
    "label": "Single-Shot-Antibiose mit Cefuroxim eintausendfünfhundert Milligramm neue Zeile Prolene sechs null fortlaufend."
  }
]
```

Create `data/demo/seed.sh`:

```bash
#!/bin/bash

set -e

echo "🌱 Seeding demo data..."

# Check if backend is running
if ! curl -s http://localhost:5000/health > /dev/null 2>&1; then
  echo "❌ Backend not running on http://localhost:5000"
  echo "   Start with: yarn dev:backend"
  exit 1
fi

# Prepare multipart form data
AUDIO_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/audio" && pwd)"
TRANSCRIPTS="$(cat "$(dirname "${BASH_SOURCE[0]}")/transcripts.json")"

# Call ingest endpoint
RESPONSE=$(curl -s -X POST http://localhost:5000/api/ingest \
  -F "transcripts=${TRANSCRIPTS}" \
  -F "audio=@${AUDIO_DIR}/sample_short.wav" \
  -F "audio=@${AUDIO_DIR}/sample_clean.wav" \
  -F "audio=@${AUDIO_DIR}/sample_noisy.wav")

# Parse response
INGESTED=$(echo "${RESPONSE}" | grep -o '"ingested":[0-9]*' | head -1 | cut -d: -f2)
REJECTED=$(echo "${RESPONSE}" | grep -o '"rejected":[0-9]*' | head -1 | cut -d: -f2)

if [ -z "$INGESTED" ]; then
  echo "❌ Failed to seed data. Response: ${RESPONSE}"
  exit 1
fi

echo "✅ Demo data loaded:"
echo "   📁 Ingested: ${INGESTED} items"
echo "   🚫 Auto-rejected: ${REJECTED} items"
echo ""
echo "🎯 Next steps:"
echo "   1. Open browser: http://localhost:3000"
echo "   2. Go to: /queue"
echo "   3. Click item to start annotating"
```

Make it executable:

```bash
chmod +x data/demo/seed.sh
```

Update `package.json`:

```json
{
  "scripts": {
    "seed": "bash data/demo/seed.sh",
    "dev:backend": "...",
    "dev:frontend": "...",
    ...
  }
}
```
