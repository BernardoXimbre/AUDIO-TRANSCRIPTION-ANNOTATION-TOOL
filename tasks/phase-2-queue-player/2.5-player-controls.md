## ⚡ Exactly

Enhance Player.vue with:

```vue
<!-- Add to Player.vue template after play/pause button -->
<div class="flex items-center gap-2">
  <label class="text-sm">Speed:</label>
  <select v-model.number="playbackSpeed" @change="changeSpeed" class="border rounded px-2 py-1">
    <option value="0.75">0.75x</option>
    <option value="1">1x</option>
    <option value="1.25">1.25x</option>
    <option value="1.5">1.5x</option>
    <option value="2">2x</option>
  </select>
</div>

<!-- Improved seek slider -->
<div class="mt-2">
  <div class="text-xs text-gray-500 mb-1">Click to seek</div>
  <input 
    type="range"
    v-model.number="seekValue"
    :max="duration"
    @mousedown="isSeeking = true"
    @mouseup="isSeeking = false"
    @input="handleSeek"
    class="w-full cursor-pointer hover:accent-blue-600"
  />
</div>
```

Add to script:

```typescript
const playbackSpeed = ref(1);
const isSeeking = ref(false);
const seekValue = ref(0);

function changeSpeed() {
  if (audioElement.value) {
    audioElement.value.playbackRate = playbackSpeed.value;
  }
}

function handleSeek() {
  if (audioElement.value && isSeeking.value) {
    audioElement.value.currentTime = seekValue.value;
  }
}

function updateTime() {
  if (audioElement.value && !isSeeking.value) {
    seekValue.value = audioElement.value.currentTime;
    currentTime.value = audioElement.value.currentTime;
  }
}
```
